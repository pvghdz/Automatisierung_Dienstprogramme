# Automatisierung_Dienstprogramme
Collection of automatization-related code that I have written / grabbed from multiple places

## MQTT 
Basic MQTT (mosquitto) utilities and functionalities. Useful to control Shelly devices with code, for example. I can also use them to let python scripts communicate with my phone or other MQTT-capable services. If it is only for messages though, an http service like ntfy for the smartphone might be better.
